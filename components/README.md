# Soft Life Club Store

A Vercel-ready Next.js storefront for the Soft Life Club oversized collection.

## Before launch

1. Replace each `Price to be added` value in `components/storefront.tsx` with the approved product price and currency.
2. Add individual product photography when available.
3. Create the matching Stripe products/prices and connect checkout.
4. Replace the temporary delivery announcement, contact address, and add the approved shipping, returns, privacy and terms pages.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this folder into Vercel, then add the required environment variables from `.env.example`.
